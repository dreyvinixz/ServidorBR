# Política de Segurança

## Versões com suporte

Como o ServidorBR ainda está em desenvolvimento acadêmico, somente a versão mais recente disponível na branch `main` receberá correções de segurança.

| Versão | Suporte de segurança |
| --- | --- |
| Versão mais recente em `main` | Sim |
| Versões anteriores | Não |

## Como reportar uma vulnerabilidade

Não publique vulnerabilidades, credenciais, dados pessoais ou detalhes exploráveis em Issues públicas.

Para reportar um problema de segurança, use o canal privado de [novo Security Advisory](https://github.com/dreyvinixz/servidorbr/security/advisories/new). Inclua, quando possível:

- descrição do problema e impacto potencial;
- passos mínimos para reprodução;
- arquivos, endpoint ou componente afetado;
- sugestão de correção ou mitigação, se houver.

O líder técnico confirmará o recebimento e avaliará o relato antes de qualquer divulgação pública. O prazo de correção depende da severidade e do contexto acadêmico do projeto.

## Escopo inicial

Esta política cobre o código, configurações Docker, dependências e fluxos de CI do repositório. Nunca envie senhas, tokens, connection strings ou bases de dados em Pull Requests, Issues ou commits.
